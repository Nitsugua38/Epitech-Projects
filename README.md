# Epitech Projects

A collection of some of the academic projects completed during my Bachelor of Computer Science at **EPITECH Paris**.


## 📂 Project Showcase

| Project | Type | Description | Stack |
|---------|------|-------------|-------|
| [NEXTBUY](./projects/nextbuy/) | Data Analytics & ML | Grocery order dataset analysis with EDA, business insights, customer segmentation, and predictive models (reorder prediction, cart size forecasting) | Python, pandas, scikit-learn, XGBoost, TensorFlow |
| [YOWL](./projects/yowl/) | Product Design & Web App | Social web app built through a full UX design process — from user research to MVP — aiming at presenting job offers through TikTok-style scrolling. | React, Vite, Node.js, Express, Docker |
| [ELIZA](./projects/eliza/) | AI Chatbot | Discord-integrated AI legal assistant (LexBot) that answers French law questions by citing official legal texts using a fully local RAG pipeline. | Node.js, Ollama, Mistral, ChromaDB, HuggingFace |
| [JOBAGGREGATOR](./projects/jobaggregator/) | Full Stack Web App | Tinder-style job offer aggregator with user accounts, application tracking, CV upload, advanced stats dashboard, and AI recommendations. | Node.js, Express, MySQL, Nginx, Docker |

> **Note on Contributions:** These were group projects. Please refer to the commit history in specific subdirectories to view my individual contributions to the codebase.
