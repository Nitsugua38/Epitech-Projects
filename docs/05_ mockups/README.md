### Mockups

This folder contains PNG exports for the mockups of all pages (desktop + mobile) of our project.
We chose to design a sleek and minimalist interface to provide users with an easier and more intuitive experience.
We wanted the website to be able to load fast and encourage users to stay hooked on our web app so they can enjoy applying to jobs.

Our web app is accessible since it's minimalist, not too overloaded, responsive and has big fonts.
