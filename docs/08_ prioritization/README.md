# Prioritization

This folder documents how the MVP scope was defined and justified.

It explains **which features were selected for the MVP, which were postponed or excluded, and why**, based on user research, project constraints, and a structured prioritization method.

## Contents

* **`prioritization_matrix.md`**
  Feature prioritization using the **RICE framework** (Reach, Impact, Confidence, Effort), justifying product decisions and trade-offs.

* **`mvp_definition.md`**
  Precise definition of the MVP scope, including:

  * Main user flow
  * Essential screens
  * Minimal feature set
  * Explicit exclusions

This folder defines the **functional boundary of Phase 2 (MVP Development)** and serves as a reference for all implementation decisions.
